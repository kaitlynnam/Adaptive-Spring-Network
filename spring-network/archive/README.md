# Archive

This directory preserves research branches that are no longer part of the
active profile-conditioned passive workflow.

- `timestep_adaptation/` — the complete former causal timestep-adaptive,
  preload, trajectory-evaluation, spatial-search result, and paper-artifact
  pipeline.
- `preload/` — older preload experiments and topology tools.
- `experiments/` — periodicity, update-limiting, and spring-count studies.
- `legacy/` — the original approach, optional optimizer, and project history.
- `non_active_artifacts/` — tables and datasets that do not belong to the
  active profile-conditioned passive 60-spring study, including all IsaacLab
  source/checkpoints and all `adaptive_trained_*` models.

Archived generated artifacts are stored with their corresponding branch.
