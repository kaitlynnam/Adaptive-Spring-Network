# Archive

This directory preserves research branches that are no longer part of the
active causal adaptive-stiffness workflow.

- `preload/` — archived preload experiments and topology tools.
  The active preload trainer is in `04_adaptive_learning/`.
- `isaaclab/` — IsaacLab exporter, extension, and pretrained checkpoints.
- `experiments/` — periodicity, update-limiting, and spring-count studies.
- `legacy/` — the original approach, optional optimizer, and project history.

Their generated artifacts are grouped under the matching category in
`models/`, `plots/`, `tables/`, `topologies/`, and `data/`.
