# Archived timestep-adaptive pipeline

This directory contains the former causal timestep-by-timestep stiffness
controller and all dedicated preload, trajectory, model, table, plot, test,
and paper-run artifacts. It is retained for research reproducibility but is
not imported by the active passive-control pipeline.

The active passive pipeline extracted its neutral trajectory and relaxed
mechanics helpers into `04_adaptive_learning/passive_mechanics.py`.
